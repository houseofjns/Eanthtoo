Study Notes & Key Knowledge

Use these explanations, comparisons and key terms to prepare. Content is based on the topics and uploaded Year 8 Computing papers and mark schemes, together with the topic notes supplied in the request.

1. Operating System (OS)

An operating system is system software that manages computer hardware and software resources and provides services for applications. It acts as an interface between the user and the computer.

  • Processor management: schedules CPU time for running tasks.
  • Memory management: allocates and releases RAM.
  • Device management: controls input/output devices using drivers.
  • File management: saves, names, organises and retrieves files.
  • Security: manages accounts, passwords and permissions.
  • User interface: provides GUI or CLI interaction.

Remember: opening a graphical menu demonstrates providing an interface; saving work demonstrates file management.

2. Utility Programs

Utility programs help maintain a digital device and ensure it functions smoothly. They analyse, configure, optimise or protect a computer.

  • Backup utility – creates copies of data.
  • Disk cleanup – removes unnecessary files.
  • Disk defragmenter – reorganises fragmented data on suitable HDDs.
  • Antivirus – detects, blocks or removes malware.
  • File manager – organises files and folders.
  • Diagnostic tools – identify system problems.

Two categories of system software commonly taught here are operating systems and utility programs.

3. Primary Memory

Primary memory is directly accessible by the CPU and stores instructions and data needed by the computer. Examples are RAM and ROM.

RAMROM
Volatile; loses contents when power is off.Non-volatile; retains contents without power.

Temporarily stores active programs and data.Stores essential startup instructions/firmware.

Exam terms: volatile = data is lost when power is removed; non-volatile = data is retained.

4. Secondary Storage

Secondary storage is non-volatile, long-term storage for programs and files. It keeps information when the computer is switched off.

  • HDD – magnetic storage using rotating platters.
  • SSD – flash memory, no moving parts; usually faster than HDD.
  • USB flash drive – portable flash storage.
  • Optical disc – uses laser technology, e.g. DVD.

Primary memory is directly accessed by the CPU and is generally faster; secondary storage usually offers greater capacity and long-term retention.

5. Network Types

  • PAN: Personal Area Network around one person, e.g. phone and smartwatch.
  • WPAN: wireless PAN, often Bluetooth or Zigbee.
  • LAN: Local Area Network within a home, school or building.
  • WLAN: LAN using Wi-Fi rather than network cables.
  • WAN: Wide Area Network across cities/countries; connects smaller networks.
  • WWAN: wireless WAN using cellular technologies such as 4G/5G.

Examples: smartwatch to phone = PAN; school building = LAN; offices in several countries = WAN.

6. Network Devices & Addresses

  • Router: forwards data between networks using IP addresses.
  • Switch: connects devices within a LAN and forwards frames to the correct port.
  • WAP: Wireless Access Point; allows devices to connect using Wi-Fi.
  • NIC: Network Interface Card/Controller; provides network connectivity and has a MAC address.
  • MAC address: physical address identifying a network interface.
  • IP address: logical address used to identify and route to a device on a network.

A typical all-in-one home device may combine a router, wireless access point and switch.

9. Serial & Parallel Transmission

  • Serial: sends bits one after another along a single channel/path. Uses fewer wires, can be cheaper and reliable over longer distances.
  • Parallel: sends multiple bits simultaneously using multiple channels/paths. Timing skew can occur over longer distances.

Key contrast: serial = sequential; parallel = simultaneous.

10. Bandwidth & Echo Check

Bandwidth is the amount of data that can be transferred in a given time, commonly expressed in bits per second (bps).

Echo check: the receiver sends the received data back to the sender. The sender compares the echoed data with the original. If they differ, an error has occurred and the data may need to be sent again.

11. Network Security

  • Firewall: monitors incoming/outgoing traffic and allows or blocks it using security rules. Helps prevent unauthorised access.
  • Antivirus: detects, blocks and/or removes malware such as viruses.
  • Anti-spyware: detects/removes spyware and helps prevent secret monitoring or personal-data collection.
  • Encryption: scrambles data so it is unreadable without the correct key.
  • Authentication: checks identity, e.g. password.

Wireless protection examples: WPA/WPA2/WPA3 encryption, strong password, network authentication, MAC address filtering, hidden SSID and firewall.

12. Malware & Threats

  • Virus: malicious code that attaches to a file/program and can spread when the infected host runs.
  • Trojan horse: pretends to be legitimate software to trick users into installing it.
  • Spyware: secretly monitors activity or collects information; keyloggers record keystrokes.
  • Adware: displays unwanted advertisements and may track browsing.
  • Ransomware: blocks access to files/system, often demanding payment.
  • Worm: self-replicates and spreads across networks without needing to attach to a host file.

The file extension .vbs stands for Visual Basic Script.

13. Servers

A server is a program or physical computer that provides resources, data or services to client computers over a network.

  • File server – stores and shares files.
  • Print server – manages shared printers/print jobs.
  • Mail server – sends, receives and stores email.
  • Web server – delivers web pages/content to browsers.

14. Logic Gates & Truth Tables

15. Binary & Denary

Binary is base 2 and uses 0 and 1. An 8-bit number has place values:

128 · 64 · 32 · 16 · 8 · 4 · 2 · 1

To convert denary to binary, decide which place values add up to the denary number. Example: 30 = 16 + 8 + 4 + 2 = 00011110.

To convert binary to denary, add the place values where the bit is 1. Example: 01100100 = 64 + 32 + 4 = 100.

16. Augmented Reality (AR)

Augmented reality adds computer-generated information or objects to a view of the real world. In education, a learner may view a 3D heart model over a real textbook. In gaming, virtual characters can appear in real surroundings. With robotics, AR can display information or instructions over a real robot.

AR adds to the real world; it is not the same as a completely computer-generated virtual world.
